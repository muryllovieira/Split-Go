# Split&Go

Plataforma de gestão e rateio inteligente de despesas em grupo (viagens, repúblicas, eventos), com suporte a múltiplas moedas e liquidação otimizada de dívidas.

> MVP em desenvolvimento — acompanhe pelo [board do projeto](https://github.com/users/muryllovieira/projects/1).

## Stack

| Camada         | Tecnologia                              |
| -------------- | --------------------------------------- |
| Frontend       | React + TypeScript (Vite), Tailwind CSS |
| Backend        | Java 21 + Spring Boot 3                 |
| Banco de dados | PostgreSQL + Flyway                     |
| Infra local    | Docker Compose                          |
